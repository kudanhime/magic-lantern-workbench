# 魔灯工作台 / Magic Lantern Workbench

**魔灯素材的一站式处理工作台。**

照片和视频都在同一个软件里完成——CR2/DNG 双感光度照片的检测、合并、调色、评分、批量导出；
MLV 视频的预览、调色、转码导出，**一个界面全包，不用来回切软件**。

基于开源项目 [MLV-App](https://github.com/ilia3101/MLV-App)（作者 [ilia3101](https://github.com/ilia3101)）二次开发，**遵循 GPL-3.0 协议**。

- 上游基线：commit [`e25c1fa`](https://github.com/ilia3101/MLV-App/commit/e25c1fa)（Fix rcd and dcb debayer for export）
- 本仓库相对上游：**19 个文件修改，+3002 / -236 行**，另新增 17 个文件
- 上游原始说明保留在 [README_UPSTREAM.md](README_UPSTREAM.md)

---

## 为什么做这个

玩魔灯的人平时要处理两类素材：

| 素材 | 形态 | 传统做法 |
|---|---|---|
| **照片** | CR2 / DNG，很多是双感光度（Dual ISO）拍的 | 先用 cr2hdr 合并 → 再进调色软件 → 再导出，几个软件来回倒 |
| **视频** | MLV 原始视频 | 专用播放器预览 → 调色 → 转码，又是一套工具 |

**这个版本把两条线合进一个界面。** 要处理的是照片还是视频，丢进来就行——
**导入 → 调色 → 评分筛选 → 批量导出**，全程不切软件。

---

## 一、图片编辑

这是本工作台用得最多的功能。魔灯拍的照片以 CR2 和 DNG 为主，很多带双感光度，需要先合并再调色，
整套流程都在这里走完。

### 1.1 支持的格式

| 类型 | 扩展名 |
|---|---|
| 佳能 RAW | `.cr2` `.cr3` `.crf` |
| 通用 RAW | `.dng` `.nef` `.arw` `.raw` `.sr2` `.srf` `.nrw` |

**三种导入方式**：

1. 左侧栏「**导入 CR2 照片**」卡片 → 多选文件
2. 菜单 `文件 → 转码并导入`
3. **直接把 RAW 文件拖进窗口**（拖放任意位置都行）

导入后素材会自动标记为「图片」类型，可以和视频混在同一个素材列表里管理。

### 1.2 双感光度（Dual ISO）处理

| 能力 | 说明 |
|---|---|
| **自动识别** | 载入后读取 ISO pattern（`dBBd` 等），识别双感光度素材 |
| **自动合并** | 导出 DNG 时自动合并，条纹消除 |
| **参数可手调** | 面板里有 ISO pattern 下拉、直方图曝光匹配、黑电平 delta、EV 校正、插值方式（AMaZE / mean）、别名图、全分辨率混合 |

> ⚠️ **如实说明**：本工具的 DualISO 合并是按「同 ISO」强制合并的（CR2→MLV 转换时丢了 ISO 差值信息），
> 暗部会略浑、带轻微绿偏。要极致画质仍然推荐用 cr2hdr 专用工具先合并，再把 DNG 拿进来调色。

### 1.3 完整调色链

不是简单滤镜，是 RAW 域的专业调色管线：

| 分类 | 参数 |
|---|---|
| **基础影调** | 曝光、对比度、高光、阴影、白色、黑色、清晰度、纹理、锐化 |
| **白平衡** | 色温（2000–10000K）、色调、相机预设（钨丝灯 / 日光 / 阴天 / 闪光灯 / 阴影） |
| **色彩** | 饱和度、自然饱和度、HSL 八色相独立调整（色相 / 饱和 / 明度） |
| **曲线** | RGB 曲线 + 单通道曲线编辑 |
| **色彩分级** | 三段（阴影 / 中间调 / 高光）四轮调色 |
| **效果** | 暗角、胶片颗粒（含颗粒尺寸）、黑白模式 |
| **降噪** | 多档降噪，配合 RAW 域处理 |
| **镜头校正** | 暗场扣除、坏点表、焦点像素图 |

### 1.4 素材管理与筛选

| 功能 | 说明 |
|---|---|
| **0–5 星评分** | 每张缩略图底部五颗星，直接点。**再点同一颗即清零** |
| **类型筛选** | 全部素材 / 只看图片 / 只看视频 —— 照片和视频混在一起也能秒切 |
| **缩略图缩放** | 工具栏滑块，80–260 px 实时调整，照片多的时候调小一屏看更多 |
| **批量选择** | 支持 Ctrl 多选、Shift 连选、全选 |

### 1.5 导出

| 目标 | 内容 | 适用 |
|---|---|---|
| **JPG / PNG / TIFF** | **带调色，所见即所得** | 直接交付、发朋友圈、给客户看 |
| **DNG** | 原始 RAW 数据（DualISO 自动合并），**不含调色** | 后续进 Camera Raw / Lightroom 继续调 |

**导出选项**：格式、画质（1–100）、缩放（100% / 75% / 50% / 25% / 自定义宽度）、输出目录。

**两种导出模式**：

- **导出当前帧** —— 单张精修后导出
- **批量导出图片** —— 选中（或全部）照片各出一张，一次搞定一整批

> DNG 不带调色是**设计如此**，和相机 RAW 逻辑一致——RAW 永远保持原始数据，编辑信息留给下游软件。

### 1.6 AI 自然语言调色

照片和视频共用。用一句话描述想要的效果，由大语言模型翻译成调色参数并应用：

> 天空更蓝一点，人物提亮，加一点胶片颗粒

任何 **OpenAI 兼容**的 `/v1/chat/completions` 端点都能接，本地模型（LM Studio / Ollama）也行。
详见下方 [AI 智能调色怎么配置](#ai-智能调色怎么配置)。

## 二、视频处理（MLV）

魔灯录制的 MLV 原始视频，功能完整保留自上游。

| 环节 | 能力 |
|---|---|
| **预览** | 实时播放、曝光/白平衡/调色实时预览、直方图、假色、斑马纹 |
| **去马赛克** | AMaZE / RCD / DCB / IGV / LMMSE 等多种算法 |
| **音频** | 波形显示、音频导出 |
| **导出** | ProRes、DNxHD、H.264、H.265、CinemaDNG、TIFF、PNG、JPEG、WAV |
| **帧操作** | 导出当前帧、批量导出图片 |
| **代理/转码** | 导入外部视频转 MLV |
| **FCPXML** | 导出时间线给 Final Cut Pro |

## 三、界面与语言

### 3.1 完整中文化

- 独立的中文翻译文件（`mlvapp_zh_CN.ts` / `.qm`），**878 条译文**
- 界面、菜单、对话框、状态提示、导出选项全部中文
- 保留 144 条专业术语原文（编解码器名、色彩空间名、算法名、快捷键符号），**故意不翻译**——这些词行业里就用英文

### 3.2 界面内即时切换语言（不用重启）

上游没有 i18n 基础设施，本版从零加了：

- 全局 `QTranslator` 常驻
- 4 个窗口（主窗口 / AI 面板 / 图片导出 / LLM 设置）响应 `QEvent::LanguageChange`，一次刷新所有 `.ui` 控件
- 切换语言**窗口不关、素材不丢、参数保留**

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+Z` | 切中文 |
| `Ctrl+Alt+E` | 切英文 |

菜单路径：`语言 / Language → 中文 / English`

### 3.3 12 步新手导览

**首次启动会自动弹出**，一圈带你把核心功能过一遍：

- 有「**跳过**」按钮，也可以直接按 `Esc` 结束
- 看过一次后**不再自动弹出**（会记住状态），随时可从 `帮助 → 功能导览` 重看
- 空素材状态下也能完整走完（AI 面板等环节会自动展开）

## 四、修掉的上游问题

这几个问题不修，在中文环境下基本没法用：

| 问题 | 根因 | 修复 |
|---|---|---|
| **中文路径打不开** | Windows 分支用 `toLatin1()`，中文路径变成 `?`，`fopen` 直接失败且**不报错** | 21 处改 `toLocal8Bit()` |
| **拖放文件没反应** | `dragEnterEvent` 是空实现，没有 `acceptProposedAction`，Qt 根本不触发 drop | 补 accept + `#include <QMimeData>` |
| **导入 CR2 弹两次框** | 设计成「选照片 → 再选目标文件夹」 | 去掉第二个框，MLV 直接落在源照片同目录 |

## AI 智能调色怎么配置

打开 `AI 智能调色` 面板 → 填写：

| 字段 | 说明 |
|---|---|
| 端点 | 例如 `https://api.deepseek.com/v1`、`http://127.0.0.1:1234/v1`（LM Studio）、`http://127.0.0.1:11434/v1`（Ollama） |
| 模型 | 端点支持的模型名，例如 `deepseek-chat` |
| API 密钥 | 云端服务需要；本地模型通常留空 |
| 超时 / 输出上限 | 推理型模型建议把输出上限调到 2000 以上 |

填好后回面板输入自然语言，模型会返回结构化参数，确认后应用到当前帧。

> 这是**可选功能**。默认不预填任何端点——不填端点，其余所有功能（导入、调色、评分、导出）都正常使用。

## 下载与使用

1. 到 [Releases](../../releases) 下载最新的 zip
   - `MagicLanternWorkbench_CN_vX.X_日期.zip` —— **中文版**（包内程序是 `魔灯工作台.exe`）
   - `MagicLanternWorkbench_EN_vX.X_日期.zip` —— **英文版**（包内程序是 `MagicLanternWorkbench.exe`）
   - 两个包内容完全一致，只有程序名和界面语言不同，**下你需要的那个就行**
2. **解压到任意路径**（本版修好了中文路径问题）
3. 双击里面的 `魔灯工作台.exe`（英文版是 `MagicLanternWorkbench.exe`）

⚠️ **不要只把 exe 单独拷走**，它依赖同目录的 DLL 和 `platforms/` 等文件夹，必须整个目录一起用。

### 快速上手

**处理照片：**

```
点左侧「导入 CR2 照片」→ 选照片（或直接拖进来）
→ 右侧面板调色（双感光度会自动识别）
→ 点星星评分 → 「批量导出图片」出 JPG
```

**处理视频：**

```
文件 → 打开（或拖 .MLV 进来）→ 调色 → 文件 → 导出
```

## 从源码编译

环境：**Qt 5.15.2 + MinGW 8.1**（Windows）

```bash
# 1. 生成翻译文件
lrelease platform/qt/mlvapp_zh_CN.ts

# 2. 生成 Makefile
mkdir build && cd build
qmake ../MLV-App-src/platform/qt/MLVApp.pro

# 3. 编译
mingw32-make -j4
```

产物在 `build/release/MLVApp.exe`。

⚠️ 几个坑（都是我们踩过的）：

- `main.cpp` 里翻译加载顺序是「磁盘优先 → 内嵌资源兜底」。改完 `.qm` **必须重新编译**，因为 rcc 把 `.qm` 编进 exe 了
- Makefile **不跟踪 `.qm` 变化**，只改翻译不重新编译，界面不会变。要强制生效：删 `rcc/qrc_i18n.cpp` 和 `obj/qrc_i18n.o` 再 make
- 改 `.ui` 后如果 `ui_*.h` 没重新生成，菜单改动不会进 exe。删掉对应 `ui_*.h` 再编
